# 축구 승리 예측 + 토토 기대값

최종 확률은 두 축을 **50:50**으로 합친다.

| 축 | 내용 | 왜 필요한가 |
|---|---|---|
| **데이터 50%** | 통계 모델(Poisson + Dixon-Coles) + 배당 시장 확률 | 감정·편향 없이 과거 실력과 시장의 집단 지성을 반영 |
| **분석가 판단 50%** | Claude가 뉴스·전술·맥락을 읽고 직접 매긴 확률 | 숫자에 잡히지 않는 것(전술 상성, 감독 성향, 선수단 분위기, 대회 상황)을 반영 |

축구는 득점이 적어 운의 비중이 크다. 한 결과를 단정하지 말고 확률, 근거, 불확실성을 함께 전달한다.

## 작업 순서

### 1. 경기 확정
- 팀, 대회, 날짜, 홈/원정(또는 중립)을 확인한다. 날짜가 없으면 가장 가까운 예정 경기로 가정하고 명시한다.
- 이미 끝난 경기면 결과를 알려 주고, 원하면 "경기 전 기준" 예측을 한다.

### 2. 신뢰할 수 있는 정보 수집 (웹 검색)
훈련 데이터의 순위·선수단 정보는 낡았을 가능성이 높으니 반드시 최신 자료를 검색한다. 검색은 한 번에 병렬로 보낸다.

| 항목 | 신뢰할 만한 출처 예시 | 용도 |
|---|---|---|
| 최근 8~12경기 득실(홈·원정 분리), xG | FBref, Understat, FotMob, Sofascore, 리그 공식 사이트 | 모델 입력 |
| 리그 평균 홈/원정 득점 | FBref, footystats | 모델 기준선 |
| 부상·징계·예상 선발 | 구단 공식 발표, 감독 기자회견, Transfermarkt, 주요 언론 | 보정 + 분석가 판단 |
| 일정·동기·순위 상황 | 리그 공식 순위표 | 보정 + 분석가 판단 |
| 해외 배당 (홈/무/원정) | Oddsportal 등 여러 북메이커 평균, Pinnacle | 시장 확률 (마진이 낮아 정확) |
| 토토/프로토 배당 | 베트맨(betman.co.kr) 등 사용자가 준 배당 | 기대값 계산 |
| 전술·맥락 | 프리뷰 기사, 전문 분석 | 분석가 판단 |

- 출처는 공식/통계 사이트 > 주요 언론 > 커뮤니티 순으로 믿는다. 루머성 정보는 "미확인"으로 표시하고 수치에 반영하지 않는다.
- 출처 이름과 기준 날짜를 기록한다. 찾지 못한 데이터는 지어내지 말고 "확인 불가"로 남긴다.
- 리그 평균을 못 찾으면 기본값(홈 1.5, 원정 1.2)을 쓰고 그 사실을 밝힌다.

### 3. 분석가 판단 먼저 정하기 (Claude의 50%)
**모델을 돌리기 전에** 수집한 정보만 보고 홈/무/원정 확률을 직접 정한다. 모델 숫자를 먼저 보면 그 숫자에 끌려가서(앵커링) 독립적인 판단이라는 의미가 사라지기 때문이다.

판단할 때 볼 것:
- 전술 상성: 압박 vs 빌드업, 측면 공격 vs 풀백 약점, 세트피스 강약
- 핵심 선수 매치업과 결장의 실제 영향(대체 자원의 수준)
- 감독 성향: 원정에서 내려앉는지, 리드 시 지키는지, 로테이션 습관
- 맥락: 직전 경기 충격패/대승, 다음 경기(챔스 등)를 위한 로테이션, 더비, 감독 경질설
- 기록과 실제 경기력의 차이: 운으로 이긴 팀(득점 > xG)은 하락 위험, 그 반대는 반등 여지

판단마다 근거를 한 줄씩 적어 둔다. 보고서의 "분석가 판단" 섹션에 그대로 쓴다.

### 4. 계산
`scripts/predict.py`로 계산한다. 암산하면 확률 합이 어긋나거나 스코어 분포를 놓친다.

```bash
python <skill-dir>/scripts/predict.py \
  --home-scored 2.1 --home-conceded 0.9 \
  --away-scored 1.4 --away-conceded 1.3 \
  --league-home 1.55 --league-away 1.25 \
  --home-adj 0.95 \
  --odds 1.95 3.60 4.00 \
  --analyst 52 25 23 \
  --toto-odds 1.75 3.20 3.55 \
  --ou-odds 1.85 1.80
```

- `--odds`: 해외 북메이커 배당(시장 확률용). `--toto-odds`: 실제로 걸 토토/프로토 배당(기대값용). 토토 배당만 있으면 둘 다 그 값을 쓴다.
- `--analyst`: 3단계의 분석가 확률(%). 비중 기본값은 0.5(50%)다. 사용자가 다른 비율을 원하면 `--analyst-weight`로 바꾼다.
- xG로 기대 득점을 이미 알면 `--lambda-home 1.8 --lambda-away 1.1`로 직접 넣는다.
- 부상·동기 등은 `--home-adj` / `--away-adj`로 반영하고, 보정 폭은 `references/factors.md`를 따른다. 정성 요인을 넣을 때 그 파일을 읽는다.
- 같은 요인을 분석가 판단과 `--adj` 보정에 **이중으로 크게** 반영하지 않는다. `--adj`는 결장처럼 수치화할 수 있는 것만 작게 넣고, 해석이 필요한 맥락은 분석가 판단에서 다룬다.
- 분석가 판단과 데이터 확률이 어느 결과든 15%p 이상 차이 나면 판단 근거를 다시 점검하고, 그래도 유지하면 이유를 보고서에 분명히 쓴다.

여러 경기 조합은 `scripts/combo_ev.py`로 계산한다(각 경기 최종 확률:배당).

```bash
python <skill-dir>/scripts/combo_ev.py 55:1.75 48:2.10 30:3.40
```

### 5. 토토 기대값 해석
- **EV = 최종 확률 × 배당 − 1.** +0.05면 장기적으로 1만 원당 평균 500원 이익, −0.10이면 1,000원 손실이라는 뜻이다.
- **공정 배당** = 1 ÷ 최종 확률. 실제 배당이 이보다 높아야 가치가 있다.
- 결과 해석:
  - EV > +0.05: "가치 있음"
  - 0 ~ +0.05: "근소한 가치". 확률 오차 범위 안이라 신중해야 한다.
  - EV < 0: "가치 없음"
- 토토/프로토는 해외 배당보다 마진(`bookmaker_margin`)이 큰 편이라, 승률이 높은 팀도 EV가 음수인 경우가 흔하다. 그대로 정직하게 보여 준다. 가치가 있는 선택지가 없으면 "이 경기는 걸 가치가 낮다"고 말하는 것이 맞다.
- `quarter_kelly`(권장 비중의 1/4)는 자금 대비 금액 비율이다. 확률 추정 오차가 크므로 원래 켈리 비율이 아니라 1/4만 제시한다.
- 조합: 경기 수가 늘수록 적중 확률은 곱으로 급감하고, EV가 음수인 경기가 하나만 섞여도 전체 EV가 깎인다. 조합 추천은 단일 EV가 양수인 경기 위주로 한다.

### 6. 보고서
확률은 `final_probs` 기준, 정수 %로 반올림한다.

```markdown
## ⚽ [홈팀] vs [원정팀] 예측
[대회] · [날짜] · [홈/원정/중립] · 데이터 기준: [날짜]

### 결론
**[가장 가능성 높은 결과] ([확률]%)** — 핵심 이유 한두 문장
**토토 추천:** [가치 있는 선택 + EV] 또는 "가치 있는 선택 없음"

| 구분 | 홈 승 | 무 | 원정 승 |
|---|---|---|---|
| 데이터 (모델+시장) 50% | xx% | xx% | xx% |
| 분석가 판단 50% | xx% | xx% | xx% |
| **최종** | **xx%** | **xx%** | **xx%** |

### 토토 기대값
| 선택 | 배당 | 최종 확률 | 공정 배당 | EV | 판정 |
|---|---|---|---|---|---|
| 홈 승 | 1.75 | 51% | 1.94 | −9.9% | 가치 없음 |
| ... | | | | | |
| 2.5 오버 | 1.85 | 55% | 1.80 | +2.5% | 근소한 가치 |
마진: xx%

- 예상 스코어: 1-0 (xx%), 1-1 (xx%), 2-1 (xx%) · 기대 득점 홈 x.xx / 원정 x.xx
- 양팀 득점: xx%

### 데이터 근거
- 최근 폼, 공격/수비 지표(xG), 결장자(적용 보정), 시장 배당 비교

### 분석가 판단 근거
- 전술 상성 / 핵심 매치업 / 맥락 등, 판단 근거를 한 줄씩

### 불확실성
- 신뢰도: 높음/보통/낮음 + 이유
- 결과를 뒤집을 수 있는 요인 1~2개

출처: [사이트명들]
※ 참고용 분석이며 결과를 보장하지 않습니다.
```

## 원칙
- 최종 확률이 50% 미만이면 "승리"가 아니라 "우세"로 표현한다.
- 무승부(대부분 리그에서 약 25%)를 과소평가하지 않는다.
- 분석가 판단은 데이터와 똑같이 베끼지도, 튀어 보이려고 일부러 다르게 잡지도 않는다. 근거가 있는 만큼만 데이터와 달라야 한다.
- 여러 경기를 받으면 경기마다 한 줄 요약표(최종 확률, 최고 EV 선택)를 먼저 주고, 요청한 경기만 상세 보고서를 쓴다.
- "참고용" 문구는 마지막에 한 줄만 쓴다. 설교는 하지 않는다.
- 웹 검색이 안 되는 환경이면 먼저 알리고, 사용자가 준 데이터로만 계산하며 신뢰도를 "낮음"으로 표시한다.
