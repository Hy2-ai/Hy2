# 축구 승리 예측

목표는 "감"이 아니라 **근거 있는 확률**을 주는 것이다. 축구는 득점이 적어 운의 비중이 크므로,
한 가지 결과를 단정하지 말고 확률과 그 근거, 불확실성을 함께 전달한다.

## 작업 순서

### 1. 경기 확정
- 팀, 대회, 날짜, 홈/원정(또는 중립)을 확인한다. 사용자가 날짜를 안 주면 가장 가까운 예정 경기로 가정하고 보고서에 명시한다.
- 이미 끝난 경기라면 예측 대신 결과를 알려 주고, 원하면 "경기 전 기준" 예측을 한다.

### 2. 데이터 수집 (웹 검색)
훈련 데이터의 순위·선수단 정보는 오래되었을 가능성이 높으므로 반드시 최신 자료를 검색한다.
여러 검색은 한 번에 병렬로 보낸다. 수집 항목:

| 항목 | 용도 |
|---|---|
| 최근 8~12경기 득점/실점 (홈·원정 분리), 가능하면 xG | 기대 득점 계산의 핵심 입력 |
| 리그 평균 홈/원정 득점 | 공격력·수비력 기준선 |
| 부상·징계·결장자, 예상 선발 | 정성 보정 |
| 일정(직전 경기 간격, 다음 경기 중요도), 동기(순위 상황) | 정성 보정 |
| 북메이커 배당 (홈/무/원정, 소수 배당) | 시장 확률 비교·블렌딩 |
| 상대 전적 | 참고만 (수치 보정에 사용 안 함) |

출처(사이트명)와 기준 날짜를 기록해 둔다. 찾지 못한 데이터는 지어내지 말고 "확인 불가"로 남긴다.
리그 평균을 못 찾으면 대략적 기본값(홈 1.5, 원정 1.2)을 쓰고 그 사실을 밝힌다.

### 3. 확률 계산
`scripts/predict.py`로 계산한다. 직접 암산하면 확률 합이 어긋나거나 스코어 분포를 놓치기 쉽다.

```bash
python <skill-dir>/scripts/predict.py \
  --home-scored 2.1 --home-conceded 0.9 \
  --away-scored 1.4 --away-conceded 1.3 \
  --league-home 1.55 --league-away 1.25 \
  --home-adj 0.93 --away-adj 1.0 \
  --odds 1.95 3.60 4.00 --market-weight 0.5
```

- xG 기반 기대 득점을 이미 알면 `--lambda-home 1.8 --lambda-away 1.1`로 직접 넣는다.
- 부상·동기·일정 등은 `--home-adj` / `--away-adj` 배수로 반영한다. 보정 폭은
  `references/factors.md`의 표를 따른다. 정성 요인을 적용할 때 그 파일을 읽는다.
- 배당이 있으면 블렌딩한다. 배당 시장은 대부분의 개인 모델보다 정확하므로, 모델과 시장이
  크게 다르면(어느 결과든 8%p 이상) 모델 입력을 다시 점검하고 차이의 이유를 보고서에 설명한다.

### 4. 보고서 작성
아래 형식을 사용한다. 확률은 `final_probs` 기준, 정수 %로 반올림한다.

```markdown
## ⚽ [홈팀] vs [원정팀] 예측
[대회] · [날짜] · [경기장/홈·원정·중립] · 데이터 기준: [날짜]

### 결론
**[가장 가능성 높은 결과] ([확률]%)** — 한두 문장 핵심 이유

| 홈 승 | 무승부 | 원정 승 |
|---|---|---|
| xx% | xx% | xx% |

- 예상 스코어: 1-0 (xx%), 1-1 (xx%), 2-1 (xx%)
- 기대 득점: 홈 x.xx / 원정 x.xx
- 2.5골 오버: xx% · 양팀 득점: xx%

### 근거
- **최근 폼**: ...
- **공격/수비 지표**: ...
- **결장자·변수**: ... (적용한 보정: 홈 ×0.93 등)
- **시장 비교**: 배당 내재 확률 홈 xx% / 무 xx% / 원정 xx% — 모델과의 차이 설명

### 불확실성
- 신뢰도: 높음/보통/낮음 + 이유 (데이터 부족, 선발 미발표, 컵 대회 로테이션 등)
- 결과를 뒤집을 수 있는 요인 1~2개

출처: [사이트명들]
```

## 원칙
- **확률이 50% 미만이면 "우세"라고만 표현**한다. 예: 홈 45% / 무 28% / 원정 27%는 "홈팀이 약간 우세"이지 "홈팀 승리"가 아니다.
- 무승부를 과소평가하지 않는다. 대부분 리그에서 무승부는 약 25%로, 접전이면 가장 가능성 높은 단일 스코어가 1-1인 경우가 많다.
- 여러 경기를 한꺼번에 요청받으면 각 경기를 짧은 표 한 줄씩 요약하고, 요청한 경기만 상세 보고서를 쓴다.
- 베팅·토토 관련 질문이면 확률을 그대로 제공하되, 기대값 계산(확률 × 배당 − 1)을 보여 줄 수 있다. 예측은 보장이 아니므로 "참고용"이라는 점을 마지막에 한 줄만 적는다. 설교는 하지 않는다.
- 웹 검색이 불가능한 환경이면 그 사실을 먼저 알리고, 사용자가 준 데이터나 알려진 정보로만 계산하며 신뢰도를 "낮음"으로 표시한다.
