# 정성 요인 보정 가이드

통계 모델(Poisson)은 "평소 실력"만 반영합니다. 아래 요인은 `--home-adj` / `--away-adj`
(기대 득점 배수)로 반영합니다. 근거가 확인된 요인만 적용하고, 합산 보정은 보통 0.80~1.15
범위를 넘기지 않습니다. 과도한 보정은 모델보다 직감을 믿는 것과 같아 정확도가 떨어집니다.

| 요인 | 권장 보정 (해당 팀 기대 득점) | 비고 |
|---|---|---|
| 핵심 공격수/플레이메이커 결장 | ×0.88~0.95 | 팀 득점 비중 25%↑ 선수면 하한 쪽 |
| 핵심 수비수/골키퍼 결장 | 상대 팀 ×1.05~1.10 | 실점 증가로 상대 λ를 올림 |
| 주전 3명 이상 결장 | ×0.85~0.92 | |
| 3일 이내 연속 경기·장거리 원정 | ×0.95~0.97 | 로테이션 여부 확인 |
| 감독 교체 직후 (2~4경기) | ×1.00~1.05 | 효과가 불확실하므로 작게 |
| 동기 차이 (우승/강등 vs 순위 확정) | 동기 낮은 팀 ×0.92~0.97 | |
| 더비·라이벌전 | 양 팀 득점 ×0.95, 무승부 경향 | rho를 -0.13 정도로 |
| 악천후·나쁜 잔디 | 양 팀 ×0.93~0.97 | |
| 중립 경기장 | 홈 이점 제거: 홈/원정 대신 전체 평균 사용 | |

## 데이터 우선순위
1. **xG(기대 득점)** — 실제 득점보다 운의 영향이 적어 예측력이 높음. 있으면 득점 대신 사용.
2. **최근 8~12경기** 득실 — 시즌 초반이면 지난 시즌 데이터와 섞기 (예: 이번 시즌 60%, 지난 시즌 40%).
3. **홈/원정 분리 기록** — 표본이 5경기 미만이면 전체 기록 사용.
4. **상대 전적(H2H)** — 표본이 작고 선수단이 바뀌므로 참고만, 수치 보정에는 쓰지 않음.

## 배당 블렌딩 비중(`--market-weight`)
- 주요 리그(EPL, 라리가 등) + 마감 직전 배당: 0.5~0.7 (시장이 매우 효율적)
- 하위 리그·데이터 부족: 0.6~0.8 (모델 입력 품질이 낮으므로 시장에 더 의존)
- 배당을 구하지 못함: 블렌딩 생략, 보고서에 "시장 비교 없음" 명시

## 컵 대회·토너먼트
- 90분 기준 확률을 먼저 내고, 연장/승부차기가 있으면 무승부 확률을 진출 확률로 나눠 표시
  (단순 가정: 무승부 시 각 팀 진출 확률 = 해당 팀 승리 확률 비중, 승부차기는 50:50).
